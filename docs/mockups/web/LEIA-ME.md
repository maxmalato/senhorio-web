# Mockups da versão web

`mockups.html` é a fonte da página de mockups publicada no claude.ai (página privada do dono do projeto). Ela é uma página HTML única, sem dependências além das fontes Fredoka e Nunito do Google Fonts.

## Como ver

- Pela página publicada (o link fica com o dono do projeto).
- Localmente: o arquivo não tem `<!doctype>` nem `<head>`, porque o claude.ai monta esse esqueleto ao publicar. Para abrir no navegador, coloque o conteúdo dentro de um HTML com `<!doctype html>` e `<meta name="viewport" content="width=device-width, initial-scale=1">`.
